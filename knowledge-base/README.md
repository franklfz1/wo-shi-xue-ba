# 教材知识库 (knowledge-base/)

## 是什么

按年级、学科、单元结构化的教材知识库，是 AI 老师教学时的"教学地图"。

与 `system/knowledge-anchors/`（事实锚点库）的区别：
- **锚点库**管"对不对"——数学法则、古诗原文等标准答案
- **知识库**管"教什么"——教材单元结构、教学目标、知识要点、常见易错

## 目录结构

```
knowledge-base/
├── math/
│   ├── grade-1-upper.md    ← 人教版数学一年级上册
│   ├── grade-1-lower.md    ← 人教版数学一年级下册
│   └── ...                 ← 后续年级
├── chinese/
│   ├── grade-1-upper.md    ← 统编版语文一年级上册
│   ├── grade-1-lower.md    ← 统编版语文一年级下册
│   ├── character-lists.md  ← 识字表+写字表汇总
│   └── ...
└── _meta/
    └── textbook-index.md    ← 教材版本索引
```

## 文件格式

每个知识库文件按**教材单元**组织，每个单元包含：

```markdown
## 单元X：单元名称

### X.X 课时名称
- **教学目标**：本课需要掌握到什么程度
- **知识要点**：
  - 要点1
  - 要点2
- **常见易错**：学生最容易犯的错误
- **配套习题ID**：question-bank/ 中对应习题的 ID 前缀
```

## 使用方式

AI 老师教学时参照本知识库，按教材单元顺序组织教学。涉及具体知识点时，以知识库中的"知识要点"为准。

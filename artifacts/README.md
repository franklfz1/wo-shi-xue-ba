# artifacts/ — 教学产物存放区

所有教学过程中生成的产物统一存放在此目录，按**学科 → 类型**组织，文件名标记日期。

## 目录结构

```
artifacts/
├── math/           # 数学
│   ├── images/     # 教学图片（图示、题目配图等）
│   ├── videos/     # 教学视频
│   ├── audio/      # 音频（TTS配音等）
│   ├── html/       # 交互式教学页面
│   └── other/      # 其他格式
├── chinese/        # 语文
├── english/        # 英语
└── science/        # 科学
    ├── images/
    ├── videos/
    ├── audio/
    ├── html/
    └── other/
```

## 文件命名规则

**格式：`{YYYY-MM-DD}_{描述}.{ext}`**

| 示例 | 含义 |
|------|------|
| `2025-01-15_登鹳雀楼水墨画.png` | 语文课生成的古诗配图 |
| `2025-01-15_100以内加法练习.html` | 数学课生成的交互页 |
| `2025-01-15_登鹳雀楼朗诵.mp4` | 语文课生成的视频 |
| `2025-01-15_磁铁实验记录.md` | 科学课的实验记录 |

**规则：**
- 日期前缀必须，格式 `YYYY-MM-DD`
- 描述用中文，简短清晰，下划线分隔
- 不允许无日期前缀的文件
- 学科由所在子目录决定，文件名不再重复标注学科

## 新增学科

如需新增学科，在 `artifacts/` 下创建对应的学科文件夹，内含 `images/`、`videos/`、`audio/`、`html/`、`other/` 五个子目录。

可运行初始化脚本：
```bash
python artifacts_init.py --subject 历史
```

## 与旧目录的关系

- `generated-images/` → 迁移至对应学科的 `images/`
- `audio/` → 迁移至对应学科的 `audio/`
- `hyperframes-videos/` → 迁移至对应学科的 `videos/`
- 根目录散落的视频/图片 → 迁移至对应学科目录

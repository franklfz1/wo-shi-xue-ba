## 匹配策略

1. **精确映射：** 先查 `KNOWLEDGE_POINT_MAP`，命中则用映射后的知识点
2. **精确匹配：** 题库中 `knowledge_point` 完全等于目标
3. **子串匹配：** 目标包含题库知识点，或题库知识点包含目标
4. 若以上都未命中，返回空列表，触发 AI 兜底生成

## 新增映射

当 `todo.md` 新增知识点且题库已有对应题目时，在 `exercise_engine.py` 的 `KNOWLEDGE_POINT_MAP` 字典中添加：

```python
"todo中的知识点名": "题库中的knowledge_point值",
```

添加后重新运行引擎即可从题库选题。

## 查看题库中所有知识点

```bash
cd wo-shi-xue-ba
grep -h '"knowledge_point"' question-bank/math/grade-1/generated/*.jsonl | \
  sed 's/.*"knowledge_point": "\([^"]*\)".*/\1/' | sort -u

grep -h '"knowledge_point"' question-bank/math/grade-1/textbook/*.jsonl 2>/dev/null | \
  sed 's/.*"knowledge_point": "\([^"]*\)".*/\1/' | sort -u
```

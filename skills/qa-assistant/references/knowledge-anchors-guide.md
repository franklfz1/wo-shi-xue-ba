# 事实锚点库使用指南

> 本文件是 qa-assistant skill 的锚点库参考。

---

## 锚点库 vs 知识库的分工

| 维度 | 事实锚点库 | 教材知识库 |
|------|-----------|---------|
| 定位 | 已校验事实的精确存储 | 教材内容的结构化整理 |
| 内容 | 数学法则、公式、古诗原文、历史事件 | 教材章节、知识点、课后题 |
| 精确度 | **100%准确**，不可争议 | 以教材为准，可合理扩展 |
| 更新频率 | 低，变动需严格校验 | 中，随教材版本更新 |
| 典型文件 | `math.md`、`chinese-poetry.md` | `grade-1-upper.md` 等 |
| AI行为 | **必须与锚点库一致** | 以知识库为准扩展 |

**核心原则**：锚点库是"宪法"，AI 回答涉及锚点库内容时必须与之一致；知识库是"法律"，可合理延伸但不能矛盾。

## 锚点库文件格式规范

新增或更新锚点文件时，遵循以下格式：

```markdown
# [锚点库名称]

## 校验状态约定

| 标记 | 含义 |
|------|------|
| ✅ 已校验 | 事实准确，可作为AI回答的依据 |
| ⚠️ 待校验 | 新增内容，需人工核对后方可使用 |
| 📝 待补充 | 已知的知识缺口，标记后待补充 |

---

## [知识点分类1]

### 知识点名称

**内容**：[具体内容]
**来源**：[教材名称/权威来源]
**校验状态**：✅ 已校验
**最后更新**：YYYY-MM-DD

### 知识点名称2

...
```

## 扩展新锚点的步骤

### Step 1: 创建或找到锚点文件

```bash
# 数学相关 → system/knowledge-anchors/math.md
# 古诗文相关 → system/knowledge-anchors/chinese-poetry.md
# 新增学科 → system/knowledge-anchors/<subject>.md
```

### Step 2: 添加知识点

在对应文件中追加（遵循上述格式）：
- 事实内容必须准确，可验证
- 标注来源
- 标注校验状态（初添加为 ⚠️ 待校验）
- 标注更新日期

### Step 3: 人工校验

新增内容必须经过人工核对（查证权威来源）后，将 ⚠️ 改为 ✅。

### Step 4: 更新本指南的锚点清单

将新知识点添加到"当前锚点库清单"表格中。

## AI 使用锚点库的行为规范

1. **涉及锚点库内容时**：必须与锚点库原文一致，不自行修改表述
2. **锚点库内容与其他来源矛盾时**：以锚点库为准
3. **锚点库为 ⚠️ 待校验时**：在回答中标注"以下内容待人工核对"
4. **锚点库为空但知识库有时**：以知识库为准，但标注来源为知识库
5. **两库均无时**：诚实拒绝，明确说"我不确定"

## 常见错误避免

| 错误 | 正确做法 |
|------|---------|
| AI 自行修改古诗原文 | 必须与锚点库 chinese-poetry.md 一致 |
| AI 编造数学公式 | 必须与锚点库 math.md 一致 |
| AI 给出的单位换算有误 | 必须与锚点库 math.md 一致 |
| AI 不确定时说"大概是..." | 必须明确说"我不确定，建议查XX" |

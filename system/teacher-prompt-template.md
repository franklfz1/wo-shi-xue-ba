## 练习出题模式

### 五级难度标准

| 级别 | 名称 | 定义 | 本学科示例 |
|------|------|------|-----------|
| L1 | 基础题 | 直接套用公式/法则，单步计算 | [示例] |
| L2 | 巩固题 | 需要理解概念，可能有一层转换 | [示例] |
| L3 | 提高题 | 多步计算或需要选择方法 | [示例] |
| L4 | 拓展题 | 逆向思维或变式 | [示例] |
| L5 | 挑战题 | 综合应用，需要多种策略 | [示例] |

### 难度递进规则
- 新学知识点：从 L1 开始，连续 2 道全对升一级
- 巩固复习：从上次最高级别开始
- 发现错误：降一级重新巩固
- 每次出题 1-2 道，标注难度级别

### 出题前自检
- [ ] 我已经先算出/写出了正确答案
- [ ] 题目难度级别已标注
- [ ] 题目不超纲（不涉及未学知识点）
- [ ] 题目语言适合当前年级理解

### 批改流程
- 先说对的 → 再指出哪里可以更好 → 最后完整演示一遍
- 错题记录到 `records/<subject>/errors.md`

### `records/<subject>/mastered.md` 格式

```markdown
## 已掌握知识点

- ✅ [知识点名称]（已掌握）
- 🔴 [知识点名称]（易错：[易错描述]）

```

**图标约定**：✅ 已稳定掌握 | 🔴 已掌握但易错 | 🟡 初步掌握，需巩固

## 知识边界与防幻觉规则（必须遵守）

- **只教确定的知识**：如果对某个事实不确定，必须说"我不太确定，让我们查一下"，绝不能编造
- **不编造[学科特有内容]**：[如古诗/课文/科学事实/历史事件等，只教教材或锚点库中存在的]
- **计算必须验证**：出题前先自己算一遍/推导一遍，确保答案正确
- **引用知识点**：讲解时关联到知识体系中的具体知识点名称，不脱离体系随意发挥
- **遇到超纲问题**：如实说"这个知识你以后会学到"，不强行解释导致误导
- **事实锚点库优先**：涉及 `system/knowledge-anchors/` 中已校验的知识点时，必须与锚点库内容一致
- **[学科特有防幻觉条款]**：[根据学科特点添加]
